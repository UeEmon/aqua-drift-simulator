# 複数の音源周波数・帯域幅・安定度と、変針・変速の到達時間差

この文書では、次の 3 点を説明します。

- 目標の音源を複数の線スペクトル（トーナル）として設定する方法と、帯域幅・安定度の扱い
- 音の伝搬遅延の模擬と、変針・変速によるドップラー変化の到達時間差を推定に使う方法
- ドップラー情報から推定に使えるその他の要素（未実装の候補を含む）

## 1. 音源の設定（`source`）

| 項目 | 意味 | 既定値 |
|---|---|---|
| `source_frequency_hz` | 主トーナルの周波数 | 400 Hz |
| `bandwidth_hz` | 主トーナルの線の幅。観測者は線の中心を σ = 帯域幅/√12 の正規誤差で測る（観測者・秒ごとに独立） | 0（誤差なし） |
| `stability_hz` | 放射周波数の揺らぎ 1σ。1 次ガウス・マルコフ過程（相関時間 `stability_correlation_s`）。放射されたものなので、全観測者に同じ揺らぎが各自の伝搬遅延だけずれて届く | 0（一定） |
| `stability_correlation_s` | 揺らぎの相関時間 | 60 秒 |
| `additional_tonals` | 追加のトーナル（周波数・帯域幅・安定度・相関時間）。最大 15 本 | なし |
| `shared_recognition_bias_hz` | 認識偏り（主トーナル上の値）。他のトーナルには周波数に比例してかかる（音源の回転数などを取り違えた場合に相当） | 0 |
| `propagation_delay` | 音の伝搬遅延を模擬する。観測者には時刻 t に、t − r/c に目標が出した音（その時の位置・速度・周波数）が届く | 有効 |

画面の「観測・推定条件」タブで、帯域幅・安定度・相関時間・追加の音源周波数（1 行に「周波数, 帯域幅, 安定度」）・伝搬遅延の有無を設定できます。

観測（`DopplerObservation.tonals`）にはトーナルごとに、観測者が認識している周波数・測った線の中心・線の幅が入ります。これまでの `observed_frequency_hz` と `recognized_frequency_hz` には、主トーナルの値をそのまま入れています（最近接解析と Lloyd's mirror は主トーナルを使います）。

## 2. 推定器での扱い

- **トーナルの統合**：ドップラー係数 (1 − ṙ/c) と認識偏りの比率はどのトーナルにも共通なので、トーナル k の測定値に f1/fk を掛けると、主トーナルの測定値になります。これを逆分散の重み（帯域幅による誤差、モデル誤差、想定する安定度）で 1 つにまとめます（`engine.fused_frequency`）。
- **帯域幅**：観測者ごとに独立な誤差として、尤度の分散に加えます。
- **安定度**：推定器が想定する値は `estimator.assumed_stability_hz` です（主トーナル上の値で、真値は推定器に渡しません）。揺らぎは全観測者に共通なので、観測者の数を増やしても平均されません。1 秒ごとの更新では、観測者間で共通のずれとして周辺化します（Sherman–Morrison の式、`DopplerParticleFilter.log_likelihood`）。再配置処理（move）では行ごとの分散に加えます。
- **伝搬遅延**：粒子の位置を r/c だけさかのぼった放射時の位置で、ドップラー・探知範囲・方位を計算します（1 秒ごとの更新と再配置処理の両方）。

## 3. 変針・変速の到達時間差（`estimation/maneuver_timing.py`）

### 原理

目標が変針や変速を始めた（または終えた）瞬間 t_m から速度が変わり始めるので、各観測者の受信周波数 f(t) に「折れ点」（df/dt の段差）が生じます。この変化は音で運ばれるので、観測者 j に届くのは

  t_j = t_m + r_j / c　（r_j：t_m の目標位置と観測者 j の距離）

です。t_m は共通なので、観測者間の差 t_j − t_k = (r_j − r_k)/c が距離差、つまり観測者の組ごとの双曲線になります。これは周波数の大きさや認識偏りに依存しません。

### 折れ点の検出

各観測者の直近 40 秒（`maneuver_timing_window_s`）の f(t) を「2 次式（滑らかなドップラー曲線）＋時刻 τ 以降の傾きの段差と曲率の変化」で当てはめます。2 次式の成分は窓の長さごとに 1 回だけ射影で取り除くので、τ の候補（0.25 秒刻み）ごとの計算は内積だけです。次の条件をすべて満たしたときに折れ点とします。

- 二乗誤差の減少が chi2 × σ² を超える（σ は測定誤差と当てはめ残差の大きい方。既定 chi2 = 25）
- 傾きの段差が 0.003 Hz/s 以上
- 折れ点が窓の端から十分内側にあり、1σ の時刻誤差が 0.75 秒以下

折れ点の時刻誤差 σ は、二乗誤差が最小値から σ² 以内に収まる τ の幅に、モデル誤差の下限 0.3 秒（`maneuver_timing_sigma_s`）を加えた値です。

### まとめ方と推定への反映

最大探知距離/c（＋誤差）以内に届いた別々の観測者の折れ点を、1 つの事象にまとめます。どの観測者も検出し終えた後に、2 観測者以上の事象を推定に使います。粒子ごとに、t_m の位置（現在の速度で逆算）から各観測者までの距離を出し、t_m を重み付き平均として消去した尤度

  log L = −½ Σ_j ((t_j − r_j/c) − t_m)² / σ_j²

で粒子の重みを更新します。直近の事象は再配置処理の目標分布にも含めます。どの粒子でも説明できない事象（誤検出）は使いません。結果は推定の `metadata.maneuver_timing`（採用・不採用の件数、最新の事象の観測者ごとの時間差）に入り、「推定と真値」タブに表示します。

### 検証結果（実測）

12 観測者のリング配置で、500 秒に変針（90°→180°、1°/秒）と変速（8→12 kt）を指示した場合、検出した折れ点は次の 3 つで、各観測者の時刻は真値（放射時刻＋真の伝搬遅延）との差が 0.15 秒以内でした。

| 事象 | 放射時刻 | 観測者数 |
|---|---|---|
| 変針・変速の開始 | 500 秒 | 4 |
| 変速の終了 | 540 秒 | 3 |
| 変針の終了 | 590 秒 | 4 |

推定精度への効果（4 観測者、方位なし、乱数 4 通り、機動後 360 秒間の水平誤差の平均）は、時間差を使わない場合 269 YD、使う場合 268 YD で、差はありませんでした。時刻誤差 0.3 秒は距離差で約 450 m に当たり、誤差なしのドップラーがすでに与えている位置精度より粗いためです。周波数の大きさに頼らない情報なので、次のような場合に効く見込みがあります（未検証）。

- 認識偏りや安定度の悪さでドップラーの大きさが信用できない場合
- 観測者が少なく、ドップラーだけでは鏡像などの曖昧さが残る場合

ただし、安定度 0.05 Hz の条件では折れ点の検出しきい値が上がり、折れ点を 1 つも検出できませんでした（このときドップラーだけの水平誤差も平均 約 380 YD に悪化）。

## 4. ドップラー情報から推定に使えるその他の要素

| 要素 | 得られる情報 | 本シミュレーター |
|---|---|---|
| 周波数の値（ドップラー偏移） | 視線方向の相対速度 | 使用中 |
| 探知・非探知の境界 | 最大探知距離上にいる時刻 | 使用中 |
| 最近接（CPA）時刻と、そこでの変化率 df/dt = f v² / (c r) | 最近接距離と相対速度 | 使用中（`cpa.py`） |
| Lloyd's mirror（直接波と海面反射波の干渉） | 目標の深度 | 使用中（任意） |
| **変針・変速の到達時間差** | 距離差（双曲線）、機動時刻 | **今回追加** |
| 安定度による揺らぎの到達時間差 | 放射周波数の揺らぎは全観測者に同じ形で、伝搬遅延だけずれて届く。観測者間で受信周波数の残差の相互相関をとれば、機動がなくても距離差が常時得られる | 候補（未実装）。揺らぎが大きいほど情報が増える |
| 観測者間の周波数差（差動ドップラー） | 放射周波数・認識偏り・揺らぎが打ち消し合い、相対速度の差だけが残る | 部分的（揺らぎの周辺化で同じ効果） |
| 変化量の観測者間の比 | 機動による Δf_j = (f/c) Δv · u_j の比から、視線方向の組み合わせ（位置）と速度変化の向き | 候補（未実装） |
| ドップラーの変化率（2 階微分） | d(ṙ)/dt = (v² − ṙ²)/r から距離 | 候補（粒子フィルターが暗に使用） |
| 複数トーナルの比 | 同じ音源の線どうしの対応付け。比が変われば別音源か音源の状態変化 | 候補（未実装） |
| 周波数ごとの Lloyd's mirror の干渉模様 | 干渉の谷の位置が周波数で変わるので、深度の曖昧さが減る | 候補（現在は主トーナルのみ） |
| 海面反射波のドップラー（多重経路の線の分離） | 直接波と反射波で到来角が違い、ドップラーがわずかに違う。帯域幅が十分狭ければ 2 本の線として分かれ、深度が得られる | 候補（未実装） |
| 線幅の広がり | 積分時間中の周波数変化（df/dt）による線の広がりから、最近接付近の加速度 | 候補（未実装） |
