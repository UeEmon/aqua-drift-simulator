# 観測方式の比較（位置／距離・方位／方位のみ／ドップラー／組合せ）

当初要件の「① 位置が得られる、② 距離・方位が得られる、③ 方位のみ、の差と組合せ」の比較結果です。
最終要件では方位情報は使用しないため、**比較は解析ツールとしてのみ**提供し、実行時の推定器は
ドップラー（＋探知の有無）だけを使います。

再現コマンド:

```bash
cd backend
python -m aqua_drift.analysis.compare_modes --observers 4  --seconds 1500 --runs 20
python -m aqua_drift.analysis.compare_modes --observers 12 --seconds 1500 --runs 10
```

## 条件

| 項目 | 値 |
|---|---|
| 目標 | 対水 8 kt・HDG 090・深度 500 Ft、潮流 東1.0 / 北0.3 kt |
| 観測者 | 既定配置（2列千鳥、深度 200/350/500 Ft 交互）、潮流で漂流、位置・深度・時刻は誤差なし |
| 上限斜距離 | 6000 YD、範囲内は欠測なし |
| 方位 | 水平方位、σ = 15°（正規分布・平均0・時間方向／観測者間で独立）、15 秒間隔 |
| 距離 | σ = 距離の 2 %（**仮定値**：要件に指定なし） |
| 位置 | 水平 σ 50 YD、深度 σ 30 Ft（**仮定値**） |
| ドップラー | 1 秒・同期。計測誤差なし（分解能 0.03 Hz として扱う）。共通・時不変の周波数認識偏りを推定 |
| 探知境界（GATE） | 探知開始・終了の各時点で「斜距離 = R_max」（タイミング 1 秒以内 → σ 3 m） |
| 深度事前分布 | 0〜1500 Ft 一様相当（σ 433 Ft）を全方式に共通で付与 |
| 評価時点 | 1500 秒時点の位置・深度・対地速度 |

* **CRLB**：等速モデルのバッチ推定に対する Cramér-Rao 下限（どの不偏推定法でもこれより良くならない）
* **MC**：ガウス・ニュートン（真値近傍から開始）の RMSE。局所精度の確認用。弱観測方向では開始点に
  引きずられて CRLB より小さく出ることがあるため、**比較の主指標は CRLB** です。

## 解釈

1. **方位のみ（σ 15°）は弱い**。水平位置は数百 YD 級で、水平方位なので深度は観測できません
   （CRLB が事前分布のσ 433 Ft に張り付く）。観測者を増やしても改善は緩やかです。
2. **ドップラーのみ**は観測者が少ないと方位のみと同程度ですが、観測者数・パス数が増えると急速に
   良くなります（4 → 12 観測者で 138 → 17 YD）。共通の周波数偏りも同時に推定されます。
3. **探知の有無を使うと劇的に良くなる**。「上限斜距離以内では欠測なし」「上限斜距離は全観測者で
   共通かつ既知」という条件により、探知開始・終了の瞬間が**斜距離 = R_max という距離観測**に
   なります。ドップラーと組み合わせると、距離・方位を直接得る方式（②）より高精度になります。
   本システムの粒子フィルタは非探知（球の外）も含めてこの情報を尤度に入れています。
4. **方位を加えても、ドップラー＋探知境界に対する上積みは小さい**。σ 15° の方位は、
   ドップラーと探知境界が既に与える情報に比べて粗いためです。これは「方位情報は使用しない」
   という最終要件の判断と整合します。
5. **深度は全方式で弱め**。観測者の深度差が小さい（数百 Ft）ため鉛直方向の幾何学的な情報が乏しく、
   観測者の深度を分散させるほど改善します（観測者深度は計算に加味しています）。

> 注意：仮定値（位置・距離のσ）を変えると①②の数値は比例して変わります。`Noise` クラスの
> 引数で変更できます。
