# 観測方式の比較（位置／距離・方位／方位のみ／ドップラー／組合せ）

当初要件の「① 位置が得られる、② 距離・方位が得られる、③ 方位のみ、の差と組合せ」の比較結果です。
現在の実行系の推定器は **ドップラー＋探知の有無＋方位** を使います（方位の使用は設定で切替可能）。

再現コマンド:

```bash
cd backend
python -m aqua_drift.analysis.compare_modes --observers 4  --seconds 1500 --runs 20
python -m aqua_drift.analysis.compare_modes --observers 4  --seconds 1500 --runs 20 --pattern surround
python -m aqua_drift.analysis.compare_modes --observers 12 --seconds 1500 --runs 10
```

## 条件

| 項目 | 値 |
|---|---|
| 目標 | 対水 8 kt・HDG 090・深度 500 Ft、潮流 東1.0 / 北0.3 kt |
| 観測者 | 2列千鳥 または 目標を囲む4点（既定）、深度 200/350/500 Ft 交互、潮流で漂流、位置・深度・時刻は誤差なし |
| 上限斜距離 | 6000 YD、範囲内は欠測なし |
| 方位 | 水平方位、σ = 15°（正規分布・平均0・時間方向／観測者間で独立）、15 秒間隔 |
| 距離 | σ = 距離の 2 %（**仮定値**：要件に指定なし） |
| 位置 | 水平 σ 50 YD、深度 σ 30 Ft（**仮定値**） |
| ドップラー | 1 秒・同期。計測誤差なし（分解能 0.03 Hz として扱う）。共通・時不変の周波数認識偏りを推定 |
| 探知境界（GATE） | 探知開始・終了の各時点で「斜距離 = R_max」（タイミング 1 秒以内 → σ 3 m） |
| 深度事前分布 | 0〜1500 Ft 一様相当（σ 433 Ft）を全方式に共通で付与 |
| 評価時点 | 1500 秒時点の位置・深度・対地速度 |

* **CRLB**：等速モデルのバッチ推定に対する Cramér-Rao 下限（どの不偏推定法でもこれより良くならない）
* **MC**：ガウス・ニュートン（真値近傍から開始）の RMSE。局所精度の確認用。弱観測方向では開始点に
  引きずられて CRLB より小さく出ることがあるため、**比較の主指標は CRLB** です。

## 解釈

1. **方位のみ（σ 15°）は単独では弱い**。水平位置は数百 YD 級で、水平方位なので深度は観測できません
   （CRLB が事前分布の σ 433 Ft に張り付く）。
2. **ドップラーのみ**は配置に強く依存します。2列千鳥 4 点では 138 YD ですが、目標を囲む 4 点配置では
   18 YD、観測者 12 では 17 YD まで改善します。共通の周波数偏りも同時に推定されます。
3. **探知の有無が強い距離情報になる**。「上限斜距離以内では欠測なし」「上限斜距離は全観測者で共通かつ
   既知」なので、探知開始・終了の瞬間は「斜距離 = R_max」という距離観測です。ドップラーと合わせると
   距離・方位を直接得る方式（②）より高精度になります。
4. **方位の効果は「パス終了時の精度」より「初期収束と曖昧さの解消」に現れる**。上表（1500 秒時点の
   局所的な下限）では、方位を加えてもドップラー＋探知境界からの改善は小さめです。一方、CRLB は
   大域的な曖昧さ（鏡像解・初期の多峰性）を表しません。実行系の粒子フィルタでの検証では：
   * 目標を囲む 4 点配置：開始 240 秒後の水平誤差 177 YD → **19 YD**（方位あり）
   * 観測者が一直線（鏡像曖昧さが残る配置）：方位なしでは約 10,000 YD の鏡像解が残り、
     方位ありでは **59〜380 YD** に収束し曖昧さが解消
   このため、現在の実行系は **方位＋ドップラー＋探知境界** を使用します（方位の使用は設定で切替可能）。
5. **深度は全方式で弱め**。観測者の深度差が小さい（数百 Ft）ため鉛直方向の幾何学的な情報が乏しく、
   観測者の深度を分散させるほど改善します（観測者深度は計算に加味しています）。

> 注意：仮定値（位置・距離のσ）を変えると①②の数値は比例して変わります。`Noise` クラスの
> 引数で変更できます。MC は真値近傍から開始した局所解の RMSE です。
