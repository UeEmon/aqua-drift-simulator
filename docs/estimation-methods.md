# 推定手法：カルマンフィルタの解説と代替手法

本書は「潮流による外力を受ける潜没目標の3次元航跡処理」を対象に、カルマンフィルタ（KF）系の
考え方と限界を整理し、本シミュレーターで採用した手法（ドップラー専用の粒子フィルタ＋
resample-move＋最近接解析）を選んだ理由を示します。

## 1. カルマンフィルタ（KF）

### 1.1 状態空間モデル

離散時間 k の状態 x_k と観測 z_k を次の形で表します。

```
x_k = F x_{k-1} + w_k,   w_k ~ N(0, Q)     （運動モデル）
z_k = H x_k + v_k,       v_k ~ N(0, R)     （観測モデル）
```

本問題の自然な状態は、位置 p（東・北・深度）、**対水**速度 u、共通周波数偏り b です。

```
x = [p_e, p_n, p_d, u_e, u_n, u_d, b]
対地速度 g = u + c(p)                     （c(p): 流速場）
c(p) = a + G (p − p_ref)                   （一定期間・一定範囲で線形）
```

定針・定速（対水）を基準とすると p_k = p_{k−1} + (u + c(p))Δt です。流速場が線形なので、
この運動モデルは状態について線形（アフィン）になり、KF の予測式に素直に入ります。

### 1.2 予測と更新

```
予測:  x̂⁻ = F x̂,             P⁻ = F P Fᵀ + Q
更新:  K = P⁻Hᵀ (H P⁻ Hᵀ + R)⁻¹
       x̂ = x̂⁻ + K (z − H x̂⁻),  P = (I − K H) P⁻
```

KF は「線形・ガウス」の条件下で最小分散推定（＝事後分布そのもの）を与えます。
P がそのまま不確かさで、ある確率の存在範囲は P から決まる**楕円体**になります。

### 1.3 非線形観測への拡張

| 手法 | 方法 | 長所 | 短所 |
|---|---|---|---|
| EKF | 観測関数を現在推定値まわりで一次近似（ヤコビアン） | 計算が軽い | 初期値が悪いと発散。曲率の大きい観測（方位のみ・ドップラーのみ）に弱い |
| UKF | シグマ点で非線形変換を近似 | ヤコビアン不要、EKFより頑健 | 事後分布は依然ガウス1峰で表現 |
| 修正極座標 EKF (MP-EKF) | 方位のみ TMA で観測不能な距離成分を分離 | 方位のみの古典的対策 | ドップラー、3次元、潮流には拡張が煩雑 |
| レンジパラメタライズド EKF（ガウス和） | 未知の距離を複数仮説の EKF 群で被覆 | 初期化問題を緩和 | 仮説数の設計が必要、3次元で仮説が爆発 |
| IMM | 複数の運動モデル（等速・旋回）を確率的に切替 | 変針・変速に強い | 各モデルは KF/EKF のまま |

### 1.4 本問題で KF 系が苦しい理由

主な観測は**ドップラー周波数**（距離なし）と粗い方位（σ 15°）です。このとき：

1. **観測が強い非線形**：f = f₀(1 − ṙ/c)、ṙ は位置と相対速度の比。1 観測者・1 パスでは、
   航跡は観測者の漂流軸まわりの**回転対称な族（リング）**として決まり、ガウス1峰では表せません。
2. **多峰性（鏡像）**：観測者が一直線に並ぶと、その直線に関する鏡像解が残ります。
   EKF/UKF は片方に誤収束しても不確かさを小さく報告します。
3. **探知の有無が情報になる**：「上限斜距離以内では欠測なし」なので、非探知は
   「目標は球の外」、探知開始は「斜距離 = R_max」という**不等式・境界の情報**です。
   KF の加法ガウス雑音の枠組みには入りません。
4. **誤差がない観測**：周波数計測誤差ゼロのため尤度が極端に鋭く、線形化誤差がそのまま
   推定誤差になります。
5. **存在圏が楕円体でない**：要件の「推定存在圏」は曲がった帯や分離した領域になり得ます。

したがって KF は「解説・比較の基準」とし、実装の主推定器には採用していません。

## 2. カルマンフィルタ以外の候補

| 手法 | 概要 | 本問題への適合 |
|---|---|---|
| **粒子フィルタ（逐次モンテカルロ）** | 事後分布を重み付き粒子で表現。任意の非線形・非ガウス・多峰を扱える | ◎ 多峰・境界情報・非楕円の存在圏をそのまま表現 |
| 正則化粒子フィルタ（RPF） | リサンプル後にカーネルで粒子を拡散し退化を防ぐ | ◎ 本実装で使用（クラスタ別カーネル） |
| Resample-move / MCMC 移動 | 窓内の全観測で MH 移動し、粒子を真の事後分布に戻す | ◎ 誤差ゼロの鋭い尤度に必須。本実装で使用 |
| Progressive correction | 尤度を段階的に適用（tempering）し粒子崩壊を防ぐ | ◎ 本実装で使用 |
| バッチ最小二乗（Gauss-Newton / LM） | 窓内の全観測で定速モデルをまとめて当てはめる | ○ 局所解。本実装では MH 提案分布の生成に使用 |
| 移動ホライズン推定（MHE） | 窓付きの最適化を逐次実行。制約（R_max）を明示可能 | ○ 単峰前提。多峰時は複数起動が必要 |
| グリッド（点群）ベイズ | 状態空間を格子で被覆 | △ 7 次元では格子が爆発 |
| ガウス和フィルタ | 複数ガウスの混合 | ○ 多峰に対応するが成分管理が複雑 |
| 固定ラグ平滑化（RTS / 祖先追跡） | 後の観測で過去推定を更新 | ◎ 「過去航跡を更新する」系統に使用 |
| 最近接（CPA）解析 | ドップラー曲線の零交差・傾き・前後変化から最近接時刻・距離・相対速力 | ◎ 要件で明示。本実装で観測者・パスごとに算出 |

## 3. 本シミュレーターの推定構成

```
観測者位置・時刻（誤差なし） ─┬─> 流速場推定（線形, 探知可能時間 = R_max / 目標速力）
                               │
ドップラー・方位・探知の有無 ─┼─> 粒子フィルタ（7 状態）
                               │     ├ 予測: 対水定速 + 線形流速場 + 変針混合（粒子版IMM）
                               │     ├ 更新: 周波数尤度 + 方位尤度 + 探知境界（シグモイド） / progressive correction
                               │     ├ resample-move: 窓内バッチ尤度で多点LM → ガウス混合提案 → MH
                               │     │                 窓は不整合（変針）検出で短縮
                               │     └ 祖先追跡による固定ラグ平滑化（過去航跡の更新）
                               │
                               └─> 最近接解析（観測者×パス）: 時刻・斜距離・相対速力と誤差
                                         ↓
              現在位置・深度・HDG/COG・対水/対地/相対速力・不確かさ・推定存在圏（HDR）
```

* **方位**：水平真方位を「ラップした角度差／σ」の正規尤度として逐次更新・resample-move・LM の
  すべてに入れます。σ 15° と粗いため終盤の精度への寄与は小さい一方、初期の多峰性と一直線配置の
  鏡像解を素早く解消します（`estimator.use_bearing` で切替）。
* **共通周波数偏り b** は状態に含めて推定します。全観測者に共通・時間変化なしという条件から、
  複数観測者・複数パスの情報で b が分離でき、検証では真値 0.2 Hz に対し 0.200 Hz を得ています。
* **過去航跡の2系統**：ONLINE は各時刻のフィルタ出力を凍結（更新しない）、SMOOTHED は
  再計算範囲（秒、可変）内の過去点を後の観測で更新します。範囲外の点は凍結されます。
* **推定存在圏**：粒子の重み付き分布から、指定確率（%）に達する最小体積のボクセル集合
  （最高密度領域, HDR）を抽出します。楕円体に当てはめないため、帯状・分離した領域を
  そのまま表示します。各連結成分の確率質量も表示します。
